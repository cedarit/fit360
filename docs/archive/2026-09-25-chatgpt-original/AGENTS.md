# Fit360 agent guidance

Before undertaking product, curriculum, architecture, safety, or implementation work, read [docs/PROJECT_CONTEXT.md](docs/PROJECT_CONTEXT.md) in full.

- Preserve the medical-literacy—not-medical-practice—boundary; do not add diagnostic, treatment, rehabilitation, or therapeutic-nutrition functionality or copy.
- Treat `docs/curriculum/` as the canonical curriculum source. Curriculum approval precedes broad feature development.
- Use the Jira → branch → pull request → review workflow and practice TDD.
- Never commit secrets, credentials, or private health data.
